# Client Manager Skill

This skill is designed to manage client IDs for Mika Automation LLC. It provides functionality to generate unique, human-readable client IDs, list all registered clients, and retrieve specific client details.

## Features

- **Generate Client IDs:** Create new, unique client identifiers based on client names.
- **List Clients:** View a comprehensive list of all clients currently managed by the system.
- **Retrieve Client Details:** Fetch detailed information for a specific client using their ID or name.
